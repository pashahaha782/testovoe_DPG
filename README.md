# Отчёт

«Если оставить сайт открытым, ноутбук начинает гудеть»: цены запрашивались каждые 2 секунды, платежи считались на все квартиры сразу. Оставил расчёт по формуле и обновление каталога только когда цена меняется.

«Прокрутка дёргается, особенно в начале, где видео»: кадр перематывался на каждый пиксель. Теперь это один раз за кадр и только пока ролик на экране, ниже видео уже не трогается.

«Каталог квартир открывается долго, а фильтры подтормаживают»: после общего списка шло ещё много запросов, поиск качал файл заново на каждую букву. Убрал эти запросы, поиск идёт по списку в памяти, фильтры переключаются сразу.


# Larch Quay

Landing page for the Larch Quay residential quarter.

## Requirements

- Node 24

## Setup

```
npm install
```

## Commands

- `npm run dev` starts the dev server on http://localhost:5173
- `npm run build` creates a production build in `dist`
- `npm run preview` serves the production build on http://localhost:4173
